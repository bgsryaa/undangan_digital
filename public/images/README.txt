Taruh foto-foto berikut di folder ini (nama file harus sama persis
supaya cocok dengan src/data/wedding.ts):

  groom.jpg        -> foto mempelai pria
  bride.jpg        -> foto mempelai wanita
  hero.jpg         -> foto utama pasangan (hero section)
  gallery-1.jpg ... gallery-9.jpg  -> 9 foto galeri

Sementara folder ini kosong, Next.js akan menampilkan gambar rusak (broken image)
di tempat-tempat tersebut. Ganti dengan foto asli sebelum publish, atau ubah
path-nya langsung di src/data/wedding.ts jika ingin memakai nama file lain
atau URL foto online.
